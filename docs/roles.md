# Роли и рабочий процесс

## Роли

| Роль | Назначение |
| --- | --- |
| `admin` | Пользователи, правила логинов, кампании, группы, бэкапы и все записи. |
| `manager` | Координация рабочих операций, доступных куратору. |
| `operator` | Импорт и массовые операции в разрешённых сценариях. |
| `assistant` | Подготовка миграции и сверка приказов. |
| `viewer` | Просмотр без административных изменений. |

Саморегистрация создаёт неодобренную заявку `assistant`. Доступ появляется
только после решения администратора. Архивная кампания остаётся доступной для
чтения, но изменения в ней блокируются.

## Типовой процесс кампании

1. Администратор выбирает год и настраивает правила логинов.
2. Сотрудник загружает абитуриентов и проверяет предпросмотр.
3. Исправляются email, оплата, дубли и конфликты.
4. Создаются академические и, при необходимости, глобальные группы курса.
5. Готовые абитуриенты переводятся в кандидаты.
6. Загружается приказ, выполняется сверка ФИО, специальности и группы.
7. Подтверждённые кандидаты становятся студентами.
8. Результат выгружается для Moodle; пароль в нём всегда служебный `cron`.
9. После завершения год архивируется.

Страницы «Проверка данных» и «Мастер миграции» показывают блокирующие проблемы.
Неоднозначные совпадения требуют решения человека и не применяются автоматически.
