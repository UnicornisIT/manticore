# Аудит и унификация поиска

Дата: 2026-09-15.

## Найденные интерфейсы

Аудит выполнен до изменений через поиск по всем шаблонам, `static/`, Python/JS-файлам, включая `app.py`, `contingent.py`, `contingent_web.py`. Проверены поисковые input, q/search/query/filter, placeholders, обработчики input/submit/change/keyup, LIKE/LOWER/INSTR и нормализация строк.

| Интерфейс | Прежнее поведение | Новое поведение |
| --- | --- | --- |
| Ctrl+K и поле в навигации (`base.html`, `app.js`) | Запуск через Enter/кнопку; SQLite LIKE | Автоматический JSON-запрос с первого символа; Unicode-safe SQL |
| Страница `/search` | GET с перезагрузкой | Fetch HTML, замена только результатов, GET fallback |
| Абитуриенты, q | GET с перезагрузкой; корректный casefold на сервере | Fetch HTML с сохранением остальных фильтров, сортировки и экспорта |
| Студенты: фамилия, имя, логин; оба шаблона списка | GET с перезагрузкой; Python casefold после получения строк | Fetch HTML; фильтрация в SQL через общую нормализацию |
| Сверка контингента (`_contingent.html`, `contingent.js`) | Локальный input, lowercase | Общие debounce, composition и нормализация |
| Распределение логинов (`abiturients_to_students.html`) | Локальный input, lowercase | Общий механизм для поиска ФИО, логина, группы, специальности |
| Предварительный состав приказа: общий поиск и статус | Локальный input, lowercase | Общий механизм; одинаковые поля и нормализация для таблицы и экспорта |
| Модальные проблемные выборки приказа | Локальный input; экспорт всей выборки | Общий механизм; экспорт учитывает поисковую строку; загрузка модалки защищена от старых ответов |
| Документация | Локальный input, lowercase и отдельная замена ё | Общий Unicode casefold и нормализация пробелов |

В отдельных таблицах дублей, конфликтов логинов, пользователей, административных настроек, аудита, групп и мастера миграции дополнительных текстовых поисковых полей нет. Дубли и конфликты доступны через глобальный поиск. Select-фильтры, поля редактирования, правила генерации логинов и технические LIKE-запросы не являются свободным текстовым поиском. Новые поисковые поля в эти интерфейсы не добавлялись.

## Реализация

- `static/js/live-search.js`: общий debounce 180 мс, обработка input/composition, контроллер GET-форм с data-атрибутами.
- При каждом вводе предыдущий HTTP-запрос отменяется немедленно, до debounce. Номер запроса исключает применение устаревших ответов даже при игнорировании abort транспортом.
- HTML получается через существующие авторизованные GET-маршруты. DOMParser извлекает область результатов; поля ввода остаются теми же DOM-узлами. Скрипты полученной страницы не исполняются.
- FormData сохраняет select-фильтры и скрытые order_by/order_dir. URL обновляется через history.replaceState после успешного ответа. Ссылки сортировки и экспорта учитывают ввод, включая период debounce.
- Очистка списка запрашивает результаты без текстового ограничения, сохраняя остальные фильтры. Пустой Ctrl+K очищает результаты без HTTP.
- Локальные поиски используют только уже отображаемые данные; вся база ради клиентского поиска не загружается.
- Ctrl+K, стрелки, Enter для открытия выбранной записи, Escape и мышь сохранены. Enter также остаётся совместимым ручным запуском, но больше не требуется.
- GET-формы и кнопки сохранены для работы без JavaScript. Дизайн не переделан; индикатор загрузки не мигает, ошибка выводится через role=status.
- После обновления таблицы актуализируется контроллер выбора строк, включая новый checkbox «Выбрать всё».

## Unicode

Единая серверная функция — существующая `normalize_search_text`: `' '.join(str(value or '').split()).casefold()`.
Глобальный поиск во всех четырёх таблицах и фильтры студентов используют зарегистрированную SQLite-функцию `NORMALIZE_SEARCH` и параметризованный `INSTR(NORMALIZE_SEARCH(field), ?) > 0`. Кампании, ограничения доступа, порядок и лимит глобальных результатов сохранены. Поиск абитуриентов сохранил тот же механизм. Экспорт приказов использует эту же нормализацию.

Общая клиентская функция повторяет casefold: lowercase дополняется таблицей Unicode-исключений, сгенерированной из Python `str.casefold()`. Включены кириллица, латиница, ß и варианты греческой сигмы. Повторные пробелы схлопываются. Проценты и подчёркивания в SQL-поиске являются обычным текстом, а не LIKE-шаблоном.

Все найденные текстовые поиски работают с одного символа. Порогов 2/3 символа нет.

## Границы проверки

Новых framework и зависимостей нет. Авторизация, роли, CSRF и правила видимости паролей не изменены. Проверки frontend выполнены автоматически в DOM-фикстурах и статически; ручной прогон в настоящем браузере не выполнялся. Локальные таблицы сохраняют существующий способ загрузки данных. Их URL не синхронизируется: сохранение URL реализовано для серверных страниц списков.
