# Linux-развёртывание и эксплуатация

## Перед началом

Production-развёртывание рассчитано на Linux с Python 3.11, systemd, Nginx и
отдельным системным пользователем. Подготовьте DNS и TLS-сертификат до открытия
доступа пользователям. Работайте только с резервной копией реальной базы и не
помещайте `.env`, SQLite-файлы, загрузки или бэкапы в Git.

## Установка

Из проверенного checkout выполните от root:

```bash
sudo bash deploy.sh /srv/manticore example.org
```

Скрипт создаёт `.venv`, устанавливает `requirements-prod.lock`, размещает
systemd-службы приложения и обновления, настраивает Nginx и ограничивает права
на `.env` и `uploads/`. Gunicorn слушает только `127.0.0.1:8000`; внешний доступ
должен идти через HTTPS reverse proxy либо доверенный VPN.

Перед запуском проверьте сгенерированный `/srv/manticore/.env`, извлеките
временный пароль администратора с правами root и смените его при первом входе.
Не публикуйте пароль в тикете, журнале или истории команд.

## TLS и сеть

`deploy/nginx.conf` — базовая конфигурация, а
`deploy/nginx-https.example.conf` — пример TLS. После успешной проверки HTTPS
установите `SESSION_COOKIE_SECURE=true`. HSTS включайте только после того, как
весь домен стабильно обслуживается по HTTPS. Не привязывайте встроенный Flask
server к общедоступному интерфейсу.

## Данные и резервные копии

- владелец runtime-каталога должен быть системным пользователем приложения;
- `.env`, база, загрузки и бэкапы не должны читаться другими пользователями;
- `BACKUP_RETENTION_DAYS` задаёт автоматический срок хранения;
- SQLite backup API и `PRAGMA quick_check` проверяют создаваемые копии;
- встроенного шифрования бэкапов нет — для внешнего хранения нужен
  зашифрованный том или архив и отдельное управление ключами;
- восстановление обязательно проверяйте на отдельной копии до аварии.

## Проверка перед вводом в эксплуатацию

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/ruff check .
.venv/bin/mypy
.venv/bin/pip-audit -r requirements-prod.lock
```

Пройдите [release checklist](../RELEASE_CHECKLIST.md), включая clean install,
миграцию копии старой SQLite, backup/restore и сценарий отказа диска. После
обновления проверьте вход, кампании, импорт, сверку приказа, экспорт и журнал.

## Службы

Шаблоны находятся в `deploy/manticore.service`,
`deploy/manticore-update.service` и `deploy/manticore-update.sudoers`.
Административное обновление разрешает только запуск заранее определённой
oneshot-службы без пользовательских аргументов. Не расширяйте sudoers до
произвольных shell-команд.
