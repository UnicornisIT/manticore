# Manticore v0.1.2 — Исправление запуска Windows Desktop и SQLite

Критическое обновление стабильности Windows Desktop. Исправлена ситуация, при которой существующая SQLite могла ошибочно обрабатываться как новая база данных или приводить к общему сообщению об ошибке запуска.

## Исправлено

- Переработана история перемещений: стрелка и линия объединены в единый адаптивный трек без горизонтального переполнения страницы.
- `create_if_missing` теперь применяется только тогда, когда файл SQLite действительно отсутствует.
- Несовместимая, повреждённая, заблокированная или недоступная база больше не открывается для записи.
- Добавлена отдельная диагностика несовпадения `schema_metadata.version` и `PRAGMA user_version`.
- Проверка совместимости выполняется до запуска Flask и импорта приложения.
- Для неподдерживаемой схемы показывается понятное специализированное сообщение.
- Добавлена повторная проверка базы непосредственно перед запуском локального сервера.
- После успешного создания новой базы флаг `create_if_missing` удаляется.
- Исправлено зависание процесса после закрытия приложения из-за незавершённого потока системного трея.

## Безопасность данных

- Неподдерживаемая SQLite проверяется только в режиме чтения.
- Автоматическое понижение версии схемы отключено.
- Существующая база не удаляется и не пересоздаётся.
- Сохранена обязательная проверка и резервное копирование перед миграциями.
- Добавлена защита от случайного уменьшения номера схемы в будущих версиях.

## Сборка и выпуск

- Release workflow разделён на отдельные диагностируемые этапы.
- EXE содержит точные VERSION, schema version и commit SHA.
- Добавлен smoke-test настоящего упакованного `Manticore.exe`.
- Проверяются создание базы, повторное открытие, `/healthz` и блокировка более новой схемы.
- Исправлено зависание GitHub Actions после завершения unit tests.

## Проверки

- 257 автоматических тестов.
- Проверена миграция старой SQLite с резервной копией.
- Проверены locked, corrupt и schema-too-new базы.
- SHA-256 неподдерживаемой базы до и после запуска полностью совпадает.
- Packaged Windows EXE успешно прошёл create/start/health/reopen smoke-test.

Рекомендуется обновиться всем пользователям Windows Desktop.
