# Manticore v0.1.3 — Множественный выбор групп и улучшения списка студентов

Версия `v0.1.3` позволяет формировать выборки сразу по нескольким академическим группам и выгружать их в Excel. Выпуск также включает изменения интерфейса, структуры проекта и документации, накопившиеся после `v0.1.2`.

## Список студентов

- Вместо выбора одной группы добавлен раскрывающийся список с галочками.
- Можно отметить несколько групп вручную.
- Добавлен поиск по названию группы без учёта регистра.
- Кнопка «Выбрать найденные» отмечает все группы, соответствующие поиску. Например, для выборки всех групп лечебного дела достаточно ввести «ЛД» и нажать эту кнопку.
- Новая выборка добавляется к уже отмеченным группам. Кнопка «Снять выбор» сбрасывает все галочки; без выбранных групп показываются все студенты.
- В заголовке фильтра отображается количество выбранных групп.
- Список студентов обновляется при изменении выбора.
- Выбранные группы сохраняются в адресе страницы и при сортировке таблицы.

## Экспорт Excel

- Экспорт учитывает все выбранные группы, а также остальные фильтры и порядок сортировки.
- Исправлена потеря повторяющихся параметров групп в ссылках сортировки и экспорта.
- Отчисленные студенты не включаются в выгрузку действующего контингента.
- Сохранена поддержка прежних ссылок с одной группой.

## Интерфейс

- В блоке фильтров списка студентов добавлены внутренние отступы по 13 пикселей, рамка и скругление.
- Кнопки «Очистить» и «Экспорт Excel» отделены от краёв блока, в том числе при переносе на следующую строку.
- На экране запуска Windows Desktop используется логотип Manticore.
- Улучшено выравнивание истории движения студента.

## Структура проекта и документация

- Конфигурация, регистрация маршрутов, миграции SQLite и часть прикладных сервисов выделены в отдельные модули.
- Добавлен упорядоченный реестр миграций и журнал применённых версий схемы.
- Усилены проверки обновлений, учётных данных и резервных копий.
- `pypdf` обновлён до `6.21.2` в production- и desktop-окружениях для устранения 11 уязвимостей, найденных `pip-audit` в версии `6.19.0`.
- `Pillow` обновлён до `13.0.0` в desktop-окружении для устранения 37 уязвимостей, найденных `pip-audit` в версии `12.3.0`.
- Добавлены проверки качества кода, поиск секретов и аудит зависимостей в GitHub Actions.
- Добавлены русские формы задач, Dependabot и английский README с переключением языка.
- Документация разделена на руководства по установке, эксплуатации и разработке.

## Проверки

- Полный `python -m unittest discover -s tests -v`: 300 тестов, 0 ошибок, 0 пропусков; время выполнения — 270 секунд.
- `node --test tests/frontend/*.test.cjs`: 55 проверок, 0 ошибок, 0 пропусков.
- Ruff: `All checks passed!`.
- mypy: ошибок нет в 15 проверенных исходных файлах.
- Python compile check и проверка синтаксиса всех JavaScript-файлов в `static/js` и `desktop/ui`: PASS.
- Проверка синхронизации метаданных, соответствия тега `v0.1.3` файлу `VERSION`, запрета runtime-файлов и `git diff --check`: PASS.
- Excel сформирован и повторно прочитан: проверены обе выбранные группы, строки, порядок сортировки и исключение отчисленных студентов.
- В полном прогоне прошли проверки справочника почтовых провайдеров и 10 000 адресов с повторяющимся доменом, миграций и резервного копирования SQLite, locked/corrupt/schema-too-new баз, нехватки места и сценариев публикации релизов.
- После обновления `pypdf` и `Pillow`: 13 проверок метаданных, безопасности и извлечения текста из синтетического PDF — PASS; чтение ICO системного трея и `pip check` — PASS.
- `pip-audit` для обоих обновлённых lock-файлов: известных уязвимостей не обнаружено.

Первый запуск в песочнице встретил ограничения Windows на переименование временных файлов и запись тестового Git-репозитория. Полный повторный прогон вне песочницы на изолированных тестовых данных завершился успешно. Эти результаты относятся к исходному коду; новый установщик Windows в рамках подготовки черновика не собирался.

## Совместимость

- Версия приложения: `0.1.3`.
- Версия схемы SQLite: `6`.
- Поддерживаемая версия Python: `3.11`.
- По сравнению с `v0.1.2` обновление включает миграции схемы базы. Перед обновлением необходимо сохранить резервную копию.
- Сам множественный выбор групп не изменяет схему SQLite.
