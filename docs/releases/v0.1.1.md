# Manticore v0.1.1 — Управление жизненным циклом студентов

В этом обновлении расширены возможности работы со студентами и улучшена Windows Desktop-версия Manticore.

## Что нового

- Добавлены отчисление и восстановление студентов с сохранением истории.
- Появился отдельный список отчисленных студентов и экспорт данных.
- Улучшены переводы между группами и приёмными кампаниями.
- Добавлены контроль вместимости групп и защита от частично выполненных операций.
- Обновлена история движения студента.
- Добавлены массовые действия со строками и улучшено управление с клавиатуры.
- Улучшена проверка электронных адресов и работа с DNS-кэшем.

## Windows Desktop

- Добавлен системный трей с русским меню.
- Улучшено восстановление окна и поведение при повторном запуске.
- Разрешён только один экземпляр приложения.
- Усилена безопасность миграций SQLite и резервного копирования.
- Улучшена работа механизма обновлений.

> **Важно:** `v0.1.1` является архивной версией. Для установки рекомендуется `v0.1.2`, содержащая критические исправления запуска Windows Desktop.

[Полный список изменений](https://github.com/UnicornisIT/manticore/compare/v0.1.0-alpha...v0.1.1)
