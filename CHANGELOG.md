# Changelog

Все заметные изменения проекта фиксируются в этом файле. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют SemVer.

## [Unreleased]

### Changed

- Репозиторий проходит поэтапный аудит безопасности, структуры и документации.

## [0.1.3] - 2026-10-10

### Added

- Первичная настройка правил логинов: администратор после первого входа должен выбрать стандартный вариант или сохранить свои правила.
- Конструктор правил логинов: шаблон, длина номера, префиксы ошибок и дублей, область уникальности, регулярное выражение года, коды специальностей и базы.
- Предпросмотр импорта абитуриентов: таблица показывает все строки файла, будущие действия, статусы и возможных тезок.
- Отчеты по строкам файла: ошибки показываются с номером строки и понятным объяснением.
- Предпросмотр загрузки студентов: база студентов меняется только после подтверждения.
- Обновление почты и оплаты отдельным файлом: данные обновляются по столбцу `Договор`.
- Двухэтапная миграция: готовые абитуриенты сначала попадают в кандидаты к зачислению, затем сверяются с приказом.
- Загрузка приказа о зачислении из Excel/CSV, а также текстовых DOCX/PDF-файлов.
- Подсказка групп по специальности: для фармации показываются группы с кодом `ФМ`, для сестринского дела — `СД` и так далее.
- Панель состояния: вместо разрозненных счетчиков есть центр задач и сводка по текущей кампании.
- Полная проверка данных: отдельная страница группирует проблемы по абитуриентам, студентам, дублям и конфликтам.
- Глобальный поиск в верхнем меню и отдельная карточка записи.
- Справочник групп по папкам года, скрытие групп, CSV-импорт, шаблон CSV и автоматическое создание следующих подгрупп.
- Мастер миграции с подготовкой кандидатов, сверкой приказа, подсказкой групп и переносом в студенты.
- Архивирование кампаний: архивная кампания остается доступной для просмотра, но закрывается для изменений.
- Резервные копии базы и восстановление из бэкапа через админку.
- Журнал действий администратора и пользователей.

### Changed

- Улучшена безопасность входа: пароли хранятся в виде хеша, старые пароли мигрируют автоматически, неудачные попытки входа ограничиваются.
- Обновлены зависимости: проект использует Flask 3.x, `pandas`, `openpyxl`, `xlrd`, `python-dotenv`, а в продакшене может запускаться через `gunicorn`.
- Добавлены файлы для Linux-развертывания через `systemd` и Nginx, пример HTTPS-конфига и workflow `pip-audit`.

## [0.1.2] - 2026-10-06

Критическое обновление стабильности Windows Desktop. Подробности —
в [заметках к выпуску](docs/releases/v0.1.2.md).

### Fixed

- Существующая SQLite больше не обрабатывается как новая база: `create_if_missing`
  применяется только к действительно отсутствующему файлу.
- Несовместимая, повреждённая, заблокированная или недоступная база не открывается
  для записи; совместимость проверяется до запуска Flask и повторно перед стартом
  локального сервера.
- Несовпадение `schema_metadata.version` и `PRAGMA user_version` диагностируется
  отдельно, для неподдерживаемой схемы показывается понятное сообщение.
- Процесс больше не зависает после закрытия из-за потока системного трея.
- История перемещений студента отображается единым адаптивным треком без
  горизонтального переполнения.

### Security

- Неподдерживаемая SQLite проверяется только в режиме чтения; автоматическое
  понижение версии схемы отключено, существующая база не пересоздаётся.

### Changed

- Release workflow разделён на отдельные диагностируемые этапы; EXE содержит
  VERSION, версию схемы и commit SHA и проходит smoke-test упакованной сборки.

## [0.1.1] - 2026-10-06

Архивная версия: для установки используйте 0.1.2. Подробности —
в [заметках к выпуску](docs/releases/v0.1.1.md).

### Added

- Отчисление и восстановление студентов с сохранением истории, отдельный список
  отчисленных и экспорт.
- Контроль вместимости групп и защита от частично выполненных операций.
- Массовые действия со строками и управление с клавиатуры.
- Системный трей Windows Desktop с русским меню; запуск только одного экземпляра.

### Changed

- Улучшены переводы между группами и приёмными кампаниями, история движения
  студента, проверка email и DNS-кэш.
- Усилена безопасность миграций SQLite, резервного копирования и обновлений.
