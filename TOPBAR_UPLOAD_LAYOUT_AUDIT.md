# Topbar, Settings и загрузка файлов — 05.09.2026

## Область изменений

Исправления внесены поверх уже изменённой рабочей копии. Предыдущие изменения не откатывались. В этой итерации не менялись backend, проверка приказов, parsing, импорт, права, авторизация и рабочая БД.

## Причины и исправления

### Поиск

В `static/css/modern.css` topbar использовал Flex, а search — `min-width:300px`, затем 220px при viewport ≤1180px. При **≤900 CSS px** media query безусловно скрывал текст и shortcut и задавал ширину 34px. Оставшийся `margin:0 auto` распределял пустое пространство по обеим сторонам иконки, оставляя её посередине панели. Абсолютного позиционирования самого search не было.

Zoom и DPI уменьшают доступную ширину в CSS pixels. Старый порог учитывал всё окно, а не свободное место после sidebar, заголовка и действий. В этом же пороге sidebar исчезал, освобождая место, но поиск всё равно сворачивался. Дополнительно `.app-authenticated {min-width:1024px}` до порога 900px создавало переполнение оболочки на ширинах 901–1023px.

Теперь Flex выделяет поиску отдельный растягиваемый `.topbar-search-slot` между заголовком и действиями. Заголовок переносится при необходимости, действия не сжимаются. Поле занимает доступную ширину до 510px и прижато вправо. **Container query проверяет ширину самого slot**: менее 220px — иконка 34×34 с общим классом `topbar-icon`; иначе поле. 220px оставляют место иконке, shortcut и читаемому фрагменту подсказки. Ширина slot не зависит от режима кнопки, поэтому обратной связи и колебания между режимами нет. Иконка находится рядом с theme/user с тем же gap 14px, hover, radius и focus, без перемещения DOM и без нового JS-обработчика.

Минимальная ширина 1024px удалена из общей оболочки. Остальные responsive правила sidebar сохранены. `app.js`, `theme.js`, токены и Desktop bridge не менялись. Ctrl+K продолжает использовать физический `KeyK` независимо от раскладки.

### О программе

В `templates/desktop_settings.html`, непосредственно в `.page-header`, была ссылка `<a href="#about">О программе</a>`. Это локальный якорь, без отдельного route или JS-handler. Удалена только ссылка. Секция `#about`, версия, Manticore, UnicornisIT, GitHub, Telegram и Email сохранены. Поиск references подтвердил другие поверхности контактов: общий footer, setup и desktop UI; они сохранены. Существующий тест доступности About для всех пяти ролей обновлён: вместо ожидания лишнего якоря проверяет отсутствие кнопки в header; проверки карточки и ссылок остаются.

### Загрузка

У `.file-picker` уже были `border-box`, постоянный border 1.5px, `minmax(0,1fr)` и перенос имени. Root cause внешней пунктирной рамки — **второй drag-handler в `modern-ui.js` на всём form** и правило `form.is-dragover {outline:2px dashed;outline-offset:4px}`. Это рисовало рамку на 6px снаружи формы, в том числе за краем карточки. Legacy hover/focus/drop дополнительно рисовали внешние shadows.

Удалены дублирующие form-handlers и внешнее outline-правило. Штатная `.file-picker` в `app.js` остаётся единственным обработчиком, включая проверку accept. Это также устраняет повторную запись отклонённого файла всплывающим form-handler.

Общий компонент в `modern.css` получил ограничение `max-width:100%`, `min-width:0`, локальный positioning context для скрытого input, перенос содержимого и семантические цвета состояний. Hover/focus/dragover используют inset shadow; заметный focus outline имеет отрицательный offset. Толщина border не меняется. `overflow:hidden` не добавлялся. Существующий flex-wrap upload-row переносит кнопку вниз при нехватке места. Валидный файл обозначается success, невалидный — danger; темы используют общие tokens.
